# 物品检索的分类与入口

全站左栏按资料对象组织，先开放「物品」；「任务」有内容后再并列加入。右侧默认搜索全部物品，按名称或 ID 定位。「装备」「素材」「解锁」是同一目录的筛选视图，结果仍指向同一物品详情。进入某个视图后保留关键词，并提供清除分类、回到全部的入口。

## 哪些条件适合放在一起

- **装备**：先选职业或部位，再限定装备等级（几级能穿）与物品品级（装备强度）。武器、防具、饰品和生产采集工具共用这套条件；工具在装备下有独立入口，钓饵则放在捕鱼用品中。灵魂水晶保留装备入口，但不应混进武器结果。
- **素材**：先按游戏细类找，例如铜矿是「石材」，青铜锭是「金属」，不要用名称后缀推断。食材归素材，做好的食品归食品。水晶既保留专门的细类，也能从素材找到；水产品既能按类浏览，也可以从捕鱼主题进入。「素材」是浏览分组，不等于每件都有配方，按配方用途查询需要独立的数据关联。
- **解锁**：沿用 xiv-companion 图鉴的非装备分类，按 `ItemAction.Type` 识别永久解锁候选，再细分通用解锁动作；宠物和乐谱也按原始物品类型收录。未细分的候选归「其他解锁」。`python scripts/unlock_snapshot.py inputs/Item.csv /path/to/ItemAction.csv inputs/game-export/items.json` 生成 `sources/unlocks.json`；ItemAction 取自下述国服 CSV 同一提交。仅当物品导出摘要匹配时显示解锁入口。
- **其余物品**：住宅等从「全部」的类型筛选访问。「其他」「杂货」不再凭名称强拆；例如金币的原始类型是「其他」而非「货币」。停止流通道具仍可检索，不以收录作为当前可获取的依据。

## 数据口径

时装预设、首次收录版本、解锁分类和职业／部位筛选的判定依据及反例见[开发笔记：游戏数据的判定口径](game-data-rules.md)。

数量、例子来自 `inputs/game-export/items.json`（国服 `2026.10.06.0000.0000`），按 `category` 即 `ItemUICategory` 计数；中文细类名按 ID 对照[国服 ItemUICategory 表](https://github.com/thewakingsands/ffxiv-datamining-cn/blob/master/ItemUICategory.csv)。下面的分组是**建议的浏览入口**，细类名是游戏数据；每个细类在清单中仅计一次。正式发布时应从与物品相同的客户端导出分类名称。

市场检索字段 `searchCategory` 不适合做主目录：51,225 件中有 34,380 件为 0。装备视图用 `EquipSlotCategory` 中值为 1 的部位（不含被封锁的部位）、`ClassJobCategory` 的职业成员及 `Level{Item}`，装备等级取自 `equipLevel`。装备快照的数据源为本地 `inputs/Item.csv`（SHA-256 `abb68a057f68e4d9d37eae76d31354555d30f76a88554d0d1c04315598c7268f`）及[国服职业、职业组与部位对照表](https://github.com/thewakingsands/ffxiv-datamining-cn/tree/ae29be8b21a32329e3356709422427540bf7e364)。参考：[灰机 Wiki 物品检索器](https://ff14.huijiwiki.com/wiki/ItemSearch)、[装备检索](https://ff14.huijiwiki.com/wiki/装备)。
